02 / Architecture

Keep storage private. Control how content is delivered.

The diagram represents the intended design, not a live AWS environment.

How the proposed design works

A visitor requests the website from CloudFront. CloudFront serves the content over HTTPS and is intended to be the permitted path to the S3 origin. Origin Access Control (OAC) can help keep the S3 bucket private while allowing the configured CloudFront distribution to retrieve objects.

Important: OAC is not configured in this project yet. The bucket, distribution, permissions, and HTTPS behaviour would need to be implemented and tested in AWS before claiming this design is operational.

03 / Security

Security principles documented in this project.

These are planned controls and review points. They should not be interpreted as live, tested cloud settings.

🔒

Private by default

Block public access to the storage bucket unless a reviewed design explicitly requires otherwise.

🗝

Limited permissions

Restrict who can change website files and avoid sharing cloud credentials.

↗

Protected transit

Plan HTTPS delivery and verify the configuration before publishing a production site.
